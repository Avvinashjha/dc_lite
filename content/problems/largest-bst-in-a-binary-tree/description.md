Find the largest **rooted subtree** of the given binary tree that is a binary search tree, and return its node count. A subtree includes its root and **all** descendants; you cannot omit inconvenient nodes.

Use strict BST ordering at every node: every value in its left subtree must be smaller, and every value in its right subtree must be larger. Equal values violate this ordering. A single node is always a valid BST.
