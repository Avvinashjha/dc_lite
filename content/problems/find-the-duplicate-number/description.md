You're given an array `nums` holding `n + 1` integers, each falling somewhere between `1` and `n` inclusive, and exactly one value is repeated in the array. Identify that repeated value, without modifying the array and using only O(1) extra space.

**Example 1:**
```
Input: nums = [1,3,4,2,2]
Output: 2
```

**Example 2:**
```
Input: nums = [3,1,3,4,2]
Output: 3
```

**Edge cases:** The same value could show up more than twice. The array is guaranteed to contain at least two elements.
