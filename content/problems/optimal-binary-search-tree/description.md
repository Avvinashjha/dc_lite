You're given a sorted list of keys along with how frequently each one is searched for. Arrange these keys into a binary search tree so that the total search cost — each key's frequency multiplied by its depth in the tree — is as low as possible.

**Example:** For `keys = [10, 12, 20]` and `freq = [34, 8, 50]`, build the binary search tree with the minimum possible total search cost.
