Given an integer array `nums`, return the **length** of its longest strictly increasing subsequence.

A subsequence keeps the original relative order but may skip elements. You may not sort or rearrange elements. Every chosen value must be greater than the previous one; equal values cannot extend the subsequence.

For `[10,9,2,5,3,7,101,18]`, one longest subsequence is `[2,3,7,18]`, with length `4`. You only need to return its length, not the subsequence itself. For `[2,2,2]`, return `1`.
