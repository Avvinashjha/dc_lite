Given the `root` of a nonempty binary tree, return its **maximum width** across all levels.

At each level, imagine the node positions in a complete binary tree. Count positions from the leftmost real node to the rightmost real node, **including both endpoints and any missing positions between them**. Missing positions outside those endpoints do not count.

A level containing just one real node has width `1`, even if that node is far to the left or right. In Example 1, the last level is `[5,3,null,9]`, so its width is `4`, not `3`.
