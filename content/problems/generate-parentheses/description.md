Given a number `n` representing pairs of parentheses, produce every combination of parentheses that is properly balanced.

A combination is valid when every opening bracket has a matching closing bracket later on, and the closing brackets never outnumber the opening ones at any point while reading left to right.

### Examples

```
Input: n = 3
Output: ["((()))", "(()())", "(())()", "()(())", "()()()"]
```

```
Input: n = 1
Output: ["()"]
```

### Constraints

- `1 <= n <= 8`
