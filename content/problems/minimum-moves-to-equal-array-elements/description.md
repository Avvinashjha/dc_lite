You're given an integer array `nums`. In a single move, you may pick any `n - 1` of its elements (that is, all but one) and increase each of them by `1`. Determine the smallest number of such moves needed to make every element in the array equal.

Each move increments **exactly `n - 1` distinct elements**, all by one; the excluded element can change between moves. Return only the number of moves. An already equal array, including a single-element array, needs `0` moves.
