You're given an `m x n` grid filled with non-negative numbers. Starting at the top-left cell and moving only right or down at each step, find a path to the bottom-right cell that keeps the sum of the visited values as low as possible, and return that sum.

**Example:** For `grid = [[1,3,1],[1,5,1],[4,2,1]]`, the cheapest path sum is `7`, following the route `1 → 3 → 1 → 1 → 1`.
