Sort an array of non-negative integers using Radix Sort — the digit-by-digit approach that repeatedly buckets numbers by one digit position (typically least significant first) using a stable sort, until every digit has been processed.

**Example:** arr = [170, 45, 75, 90, 802, 24, 2, 66] → [2, 24, 45, 66, 75, 90, 170, 802]
