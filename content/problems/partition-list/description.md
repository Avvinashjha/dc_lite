You're given the head of a linked list along with a value `x`. Rearrange the nodes so every node holding a value less than `x` appears before every node holding a value greater than or equal to `x`, keeping the original relative order within each of the two groups.

**Example:** head = [1,4,3,2,5,2], x = 3 → [1,2,2,4,3,5]
