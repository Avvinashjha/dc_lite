You're given an N×N maze made of `0`s and `1`s, where a `1` marks a cell you're allowed to step on. Starting at `(0,0)`, find every path to `(N-1,N-1)`, moving only Down, Left, Right, or Up at each step.

Do not revisit a cell within a path. Return an empty array when the source is blocked or no path reaches the destination.
