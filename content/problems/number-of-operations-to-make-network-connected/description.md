There are `n` computers labeled from `0` to `n - 1`, linked by a set of direct network cables given in `connections`. You can pull out any existing cable and use it to join two computers that aren't yet connected. Determine the minimum number of such moves needed to make the whole network reachable from any computer to any other — or return `-1` if there aren't enough cables to make that possible.

**Example:** With `n = 4` and `connections = [[0,1],[0,2],[1,2]]`, the network can be fully connected after a minimum of `1` operation.
