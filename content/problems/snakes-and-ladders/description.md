You're given an n×n snakes-and-ladders board, numbered boustrophedon-style: squares run from `1` to `n^2` starting at the bottom-left, moving right along the bottom row, then alternating direction on each row going up. Each square is either `-1` (nothing special) or the destination of a snake or ladder. Starting from square 1 and rolling a standard die each turn, find the minimum number of dice rolls needed to reach the last square, following any snake or ladder you land on along the way.
