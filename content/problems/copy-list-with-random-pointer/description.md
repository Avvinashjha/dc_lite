You're given a linked list in which every node carries, besides its usual next pointer, an extra random pointer that can point to any node in the list or to nothing at all. Build a completely independent deep copy of this list, matching the same structure.

Return the copied head, or `null` for an empty list. Allocate new nodes: neither `next` nor `random` in the copy may point into the original list. The original list must have its values and links unchanged when your function returns.
