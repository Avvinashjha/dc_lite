Given a directed acyclic graph (DAG) with vertices labeled `0` through `V - 1`, return a topological ordering.

The adjacency list `adj[u]` contains destinations v of edges `u → v`. Every such edge requires u to appear **before** v in your result.

Include every vertex exactly once, including isolated vertices and vertices in disconnected components. Any order satisfying all edges is accepted; the result does not have to be numerically sorted or lexicographically smallest. The input is guaranteed to have no directed cycles.
