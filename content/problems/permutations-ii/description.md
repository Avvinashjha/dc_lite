Given an integer array `nums`, return every distinct permutation of its values. Each permutation must use all entries exactly once, preserving the number of occurrences of each value.

Repeated values are indistinguishable: swapping two equal entries does not create a new permutation. Return each distinct arrangement once, in any outer order. The order of values within each arrangement matters.

For `nums = [1, 1, 2]`, return `[1, 1, 2]`, `[1, 2, 1]`, and `[2, 1, 1]`. If all values are equal, there is exactly one permutation. Negative values and zero follow the same rules.
