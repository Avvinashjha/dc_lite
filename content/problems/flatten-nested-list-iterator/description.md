You're given a nested list where each entry is either a plain integer or another nested list, which may itself contain integers or further nested lists to any depth. Produce a single flat array containing all the integers, in the same left-to-right order they appear in the original structure.

**Example 1:**
```
Input: [[1,1],2,[1,1]]
Output: [1,1,2,1,1]
```

**Example 2:**
```
Input: [1,[4,[6]]]
Output: [1,4,6]
```
