You're given two integer arrays, `nums1` and `nums2`. Find the length of the longest contiguous run of elements that shows up identically in both arrays, in the same order.

The matching run must be **contiguous in both arrays**; you cannot skip or rearrange elements. It may start at different indices. Return its length, not the subarray itself, and return `0` if the arrays share no element.

In Example 1, `[3,2,1]` occurs at indices `2–4` in `nums1` and `0–2` in `nums2`, giving length `3`.
