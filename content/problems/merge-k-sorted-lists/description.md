Given an array `lists` containing the heads of `k` singly linked lists, merge them into one list sorted in **non-decreasing order** and return its head.

Each input list is already sorted and may be empty. Preserve every value, including duplicates across or within lists. If all lists are empty, or `lists` itself is empty, return `null`.

You may relink the input nodes. The inner arrays in examples are a display format: your function receives an array of head nodes, not arrays of values.
