You're given an array of integers `nums` and an integer `k`. Count how many contiguous, non-empty slices of the array (subarrays) have elements that add up to exactly `k`.

Count subarrays by their start and end indices. Overlapping subarrays count separately, even when they contain the same values. The empty subarray never counts. For three zeros, all six nonempty subarrays sum to k = 0.
