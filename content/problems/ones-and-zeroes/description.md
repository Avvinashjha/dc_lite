You're given an array `strs` of binary strings, along with two limits, `m` and `n`. Choose as many strings from `strs` as you can, using each at most once, such that across all the chosen strings there are no more than `m` `'0'`s and no more than `n` `'1'`s combined. Return the largest number of strings you can select under that budget.

**Example:** With `strs = ["10","0001","111001","1","0"]`, `m = 5`, and `n = 3`, the maximum number of strings that can be formed is `4`.
