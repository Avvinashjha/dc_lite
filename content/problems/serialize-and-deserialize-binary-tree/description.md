Design a way to encode a binary tree into a single string (serialization) and then reconstruct the exact same tree structure from that string (deserialization). The encoding scheme is entirely up to you — it just needs to round-trip correctly for any tree, including ones with `null` children.

**Example:** root = [1,2,3,null,null,4,5] → "1,2,null,null,3,4,null,null,5,null,null"
