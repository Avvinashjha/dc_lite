Given a matrix of numeric `0`s and `1`s, return the area of its largest rectangle containing only `1`s.

Choose consecutive rows and consecutive columns; you cannot skip cells or rotate the rectangle. Its height and width may differ. Return the number of cells, not the coordinates. If there are no `1`s, return `0`.

In Example 1, the second and third rows each contain four `1`s, forming a rectangle of area `2 × 4 = 8`.
