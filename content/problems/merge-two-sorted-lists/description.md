Given the heads `l1` and `l2` of two singly linked lists sorted in **non-decreasing order**, merge them into one sorted list and return its head.

Keep every input value, including duplicates. Either list may be empty; if both are empty, return `null`. You may reuse and relink input nodes.

The examples display lists as value arrays, but your function receives head nodes and must return a head node, not an array. For `[1,2,4]` and `[1,3,4]`, both copies of `1` and `4` remain in `[1,1,2,3,4,4]`.
