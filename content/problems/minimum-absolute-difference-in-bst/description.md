Given the root of a binary search tree containing at least two nodes, return the smallest **absolute difference between values** of any two distinct nodes.

The chosen nodes do not have to be directly connected. This asks for a numerical difference, not the number of edges between nodes. For the BST `[10,2,20,null,9]`, values `9` and `10` give the minimum difference `1`, even though their nodes are not parent and child.
