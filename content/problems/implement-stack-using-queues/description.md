Using only standard queue operations (with one or two queues), construct a stack that behaves in last-in-first-out order. It must expose `push(x)` (place `x` on top), `pop()` (remove and hand back the top value), `top()` (peek at the top value and leave it in place), and `empty()` (check whether anything remains). Only the standard queue operations are available to you under the hood.

Calls to pop() and top() occur only when the stack is non-empty.

Allowed queue operations are enqueue at the back, dequeue from the front, inspect the front, and check size or emptiness. Implement the queue storage yourself; no queue object is supplied. `push()` has no return value, and `empty()` returns a boolean.
