Given two positive integers `n` and `k`, list the factors of `n` in increasing order and return the `k`-th one. If `n` has fewer than `k` factors, return `-1`.

A factor is a **positive divisor**: an integer d for which n % d equals zero. Count each divisor once, including 1 and n. Ranking starts at 1. For n = 12, the ordered factors are [1,2,3,4,6,12], so k = 3 gives 3.
