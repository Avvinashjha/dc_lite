Given a string `s`, work out the fewest characters you'd need to insert — at any positions — so that the resulting string reads the same forwards and backwards.

Each step inserts one character anywhere, including at either end. You cannot delete, replace, or reorder existing characters. Return the count, not the resulting palindrome.

For `"ab"`, insert `"a"` at the end to form `"aba"`, so return `1`. An existing palindrome needs `0` insertions.
