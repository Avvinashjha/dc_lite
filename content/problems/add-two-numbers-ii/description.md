You're given two non-empty linked lists `l1` and `l2` that each represent a non-negative integer, but this time with the most significant digit stored first. Add the two numbers and return the sum as a linked list in the same most-significant-digit-first order.

**Example:** Input: l1 = [7,2,4,3], l2 = [5,6,4] → Output: [7,8,0,7]
