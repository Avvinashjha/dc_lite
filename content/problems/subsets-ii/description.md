Return every distinct subset of `nums`, including the empty subset `[]`.

Each input position can be selected at most once. Repeated values may appear together when the input contains enough copies, but two choices producing the same values form only one distinct subset. Element order does not distinguish subsets.

For `[2,2]`, return `[[],[2],[2,2]]`: include `[2]` once, and do not discard the valid two-copy subset.

Subsets and the elements within each subset may be returned in any order.
