You're given an `m x n` character grid `board` and a target string `word`. Return `true` if `word` can be traced out by moving through the grid one letter at a time, stepping only to a horizontally or vertically neighboring cell at each move, and never reusing a cell already visited within that same path.

Diagonal moves are not allowed. A path may turn, and repeated letters must use different cells. Matching is case-sensitive.
