You're given two arrays, `preorder` and `postorder`, holding the preorder and postorder traversals of the same binary tree whose node values are all distinct. Return any binary tree with these traversals. The original shape is not necessarily unique.

Preorder visits root, left subtree, then right subtree. Postorder visits left subtree, right subtree, then root. When a node has only one child, these traversals cannot tell whether it is a left or right child.
