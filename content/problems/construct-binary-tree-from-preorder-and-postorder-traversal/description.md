You're given two arrays, `preorder` and `postorder`, holding the preorder and postorder traversals of the same binary tree whose node values are all distinct. Rebuild the original tree from these two traversals.

**Example:** preorder = [1,2,4,5,3,6,7], postorder = [4,5,2,6,7,3,1] → Output: [1,2,3,4,5,6,7]
