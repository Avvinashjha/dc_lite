Solve the given 9 × 9 Sudoku board **in place**.

Each cell is a character: `"1"` through `"9"` is a fixed clue, and `"."` is an empty cell. Replace only empty cells so that:

- Each row contains every digit from 1 through 9 exactly once.
- Each column contains every digit exactly once.
- Each aligned 3 × 3 box contains every digit exactly once.

Keep the original clues unchanged and write digit **strings**, not numbers. The puzzle is valid and has exactly one solution. An already completed board should remain unchanged.
