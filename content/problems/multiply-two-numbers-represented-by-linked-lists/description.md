You're given two numbers, each represented as a linked list where every node holds a single digit. Digits are stored most significant first. Return their product modulo `10^9 + 7` as an integer.

The lists represent nonnegative base-10 integers and may contain leading zeros. For example, `[0,0,3]` represents `3`, and `[3,2]` represents `32`. Return only the remainder, which lies from `0` through `1000000006`. Do not convert the full represented numbers to JavaScript Number: they may contain up to 100 digits.
