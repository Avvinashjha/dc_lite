Given a string `str`, return an object containing every character that occurs more than once, mapped to its **total number of occurrences**.

Count characters exactly as written. Uppercase and lowercase are distinct, and spaces, digits, and punctuation count too. Include each repeated character once as a property; omit characters occurring only once. Property order does not matter.

For `str = "aAa! "`, return `{"a": 2}`. For `str = "aaa"`, return `{"a": 3}`, not `{"a": 2}`: report the total count, not the number of repetitions after the first occurrence. Return `{}` for an empty string or one with no duplicates. Return the object rather than printing it.
