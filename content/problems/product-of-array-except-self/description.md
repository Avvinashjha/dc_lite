Given an integer array `nums`, return an array `result` of the same length where `result[i]` is the product of every entry except the one at index `i`.

Exclude exactly one index, not every occurrence of its value. Preserve index order in the result. Values may be negative, zero, or repeated. Solve the problem in linear time **without division**.

For `[1, 2, 3, 4]`, return `[24, 12, 8, 6]`. With exactly one zero, only the result at that zero's index can be nonzero; with two or more zeros, every result is zero.

**Follow-up:** Use constant auxiliary space, excluding the returned array.
