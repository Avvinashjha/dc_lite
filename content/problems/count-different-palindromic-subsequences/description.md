You're given a string s made up only of the letters 'a', 'b', 'c', and 'd'. Count how many distinct non-empty subsequences of s read the same forwards and backwards, and return that count modulo 10^9 + 7.

A subsequence is formed by deleting zero or more characters without changing the order of those kept. Count equal resulting strings only once, even when different choices of indices produce them. The empty string is not counted.
