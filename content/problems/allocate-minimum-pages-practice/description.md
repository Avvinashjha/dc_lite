You're given an array `arr` of `N` integers, where `arr[i]` is the page count of the `i`-th book, and you need to distribute these books among `M` students. Books must be handed out in the order they appear — each student gets a contiguous block — and every student must receive at least one book. Choose an allocation that minimizes the largest number of pages any single student ends up with, and return that minimized maximum.

**Example:** arr = [12, 34, 67, 90], M = 2 → Output: 113
