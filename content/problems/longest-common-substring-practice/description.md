Given two strings `s1` and `s2`, return the **length** of their longest common substring. A substring consists of consecutive characters; you cannot skip characters as you can in a subsequence.

The substring may start at different positions in the two strings. Comparisons are case-sensitive: `"A"` and `"a"` differ. Return `0` if no character is shared.

For `"ABCDGH"` and `"ACDGHR"`, the common substring `"CDGH"` has length `4`. For `"ABC"` and `"ACB"`, the answer is `1`: `"AB"` is a common subsequence, but it is not contiguous in the second string.
