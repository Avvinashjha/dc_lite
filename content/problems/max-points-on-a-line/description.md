You're given an array `points`, where each `points[i] = [xi, yi]` marks a point on the X-Y plane. Find the largest number of these points that can all sit on one common straight line.

Return a count, not a line equation or a list of points. The line can be vertical, horizontal, or slanted. Points are distinct, and their order in the input does not matter. With just one point, return `1`.
