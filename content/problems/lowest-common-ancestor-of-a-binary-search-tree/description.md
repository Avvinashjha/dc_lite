You're given the root of a binary search tree (BST) along with two node values `p` and `q` known to exist in it. Return the value of their lowest common ancestor (LCA) — the deepest node in the tree that has both `p` and `q` somewhere below it (a node counts as its own descendant too). Since the tree is a BST, you can lean on its ordering property to locate the LCA without touching every node.
