You're given an integer array `nums` and a window size `k`. A window of `k` consecutive elements slides across the array one step at a time, from the first position to the last. For each position of the window, record the maximum value inside it, and return these maximums as an array.

**Example:** nums = [1,3,-1,-3,5,3,6,7], k = 3 → Output: [3,3,5,5,6,7]
