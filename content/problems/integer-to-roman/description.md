Convert `num` to its standard Roman numeral representation using `I = 1`, `V = 5`, `X = 10`, `L = 50`, `C = 100`, `D = 500`, and `M = 1000`.

Write values from largest to smallest, using these six subtractive forms: `IV = 4`, `IX = 9`, `XL = 40`, `XC = 90`, `CD = 400`, and `CM = 900`. Other subtractive pairs are not allowed: for example, 49 is `XLIX`, not `IL`. Use no spaces or lowercase letters.
