Given the head of a singly linked list, return `true` if its sequence of values reads the same forwards and backwards. Otherwise, return `false`.

Compare node **values**, not node identities. A one-node list is a palindrome. For example, `[1, 2, 3, 2, 1]` is a palindrome, while `[1, 2, 3, 1]` is not.

The examples display lists as value arrays, but your function receives linked nodes with `val` and `next` properties; the last node's `next` is `null`.

**Follow-up:** Can you solve this in linear time using constant extra space? The reference solution also restores the original list after checking it.
