You're given an `m x n` character board and a list of candidate strings `words`. Return every word from the list that can be traced out on the board by moving one letter at a time to a horizontally or vertically neighboring cell, without reusing any single cell more than once within that word's path.

Return each matching word only once, even when several paths spell it. Result order does not matter. Different words may reuse the same board cells; the no-reuse rule applies separately to each individual path. Diagonal moves are not allowed, and a word may be a prefix of another matching word.
