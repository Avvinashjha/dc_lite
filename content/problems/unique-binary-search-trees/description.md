For a given integer `n`, count how many distinct binary search tree shapes can be built using exactly the keys `1` through `n` (a BST being a tree where every node's left subtree holds smaller values and its right subtree holds larger ones).

Use every key exactly once and return only the count, not the trees. Left and right child positions are distinct, so reflected shapes may count separately. Different insertion sequences that produce the same tree count only once.
