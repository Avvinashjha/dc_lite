You're given the `root` of a binary tree. Return its maximum depth — the count of nodes along the longest path starting at the root and ending at whichever leaf is farthest away.

A leaf has no children. Count nodes, not edges: an empty tree has depth `0`, and a single-node tree has depth `1`. Node values do not affect the answer.

In Example 1, a longest path is `3 → 20 → 15`, containing three nodes, so the depth is `3`.
