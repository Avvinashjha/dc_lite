You're given an array of `N` distinct values. Using swaps that exchange any two elements, determine the fewest swaps needed to arrange the array in ascending order.

One swap can exchange any two positions, even if they are far apart. Return the count, not the sorted array or the swap sequence. An already sorted array needs `0` swaps.

For `[4,3,2,1]`, swap `4` with `1`, then `3` with `2`, giving `[1,2,3,4]` in two swaps. This is not the adjacent-swap count.
