You're given an `m x n` grid of integers where each cell `grid[i][j]` means one of four things: `1` marks the single starting square, `2` marks the single ending square, `0` marks an empty square you're free to cross, and `-1` marks a blocked square. Count how many distinct routes — moving up, down, left, or right — get from start to end while stepping on every open (non-obstacle) square exactly once.
