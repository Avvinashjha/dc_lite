# SQL, JDBC, and transactions

**Real-life problem:** Persist expenses in a relational database.

**You will learn:** Relational models and SQL basics; Prepared statements and result mapping; Transactions and connection pools; Indexes, constraints, and concurrency.

## Chapter 1: Relational models and SQL basics

Create tables with primary keys, appropriate column types, and constraints. Practice SELECT, INSERT, UPDATE, DELETE, joins, and grouped aggregates. SQL NULL represents missing information and needs IS NULL rather than = NULL. Design queries from the required result and its cardinality.

**Follow the working project:** Primary keys identify rows, foreign keys link them, and constraints defend invariants even when Java callers race. Practice joins between expenses and expense_outbox and GROUP BY aggregates. A LEFT JOIN preserves unmatched left rows; NULL needs IS NULL.

File in the [reference-project download](/downloads/java-course-labs.zip): `backend/src/main/resources/db/migration/V1__expense_schema.sql`. Follow its README to build and run it.

```sql
CREATE TABLE expenses (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  version BIGINT NOT NULL DEFAULT 0,
  owner VARCHAR(255) NOT NULL,
  label VARCHAR(100) NOT NULL,
  amount INTEGER NOT NULL CHECK (amount > 0),
  spent_on DATE NOT NULL
);

CREATE TABLE expense_outbox (
  event_id VARCHAR(36) PRIMARY KEY,
  expense_id BIGINT NOT NULL UNIQUE REFERENCES expenses(id) ON DELETE CASCADE,

);
CREATE TABLE notifications (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  event_id VARCHAR(36) NOT NULL REFERENCES expense_outbox(event_id) ON DELETE CASCADE,
  expense_id BIGINT NOT NULL REFERENCES expenses(id) ON DELETE CASCADE
);
```

## Chapter 2: Prepared statements and result mapping

Use JDBC PreparedStatement parameters for values instead of concatenating user input into SQL. Parameters cannot replace arbitrary identifiers such as a table name; those need trusted allowlists. Map ResultSet columns deliberately and close the result, statement, and connection.

**Follow the working project:** PreparedStatement binds values with numbered parameters starting at one. ResultSet.next moves to the next row; column getters map it to a domain value. The same resource block closes the rows, statement, and connection.

File in the [reference-project download](/downloads/java-course-labs.zip): `developer-core/src/main/java/in/dailycoder/core/JdbcExpenses.java`. Follow its README to build and run it.

<details>
<summary>Read the complete example source</summary>


```java
package in.dailycoder.core;

import javax.sql.DataSource;
import java.sql.Connection;
import java.sql.PreparedStatement;
import java.sql.SQLException;
import java.sql.Statement;
import java.sql.Date;
import java.util.ArrayList;
import java.util.List;

public final class JdbcExpenses implements ExpenseRepository {
    private final DataSource source;
    public JdbcExpenses(DataSource source) throws SQLException {
        this.source = source;
        try (var connection = source.getConnection(); var statement = connection.createStatement()) {
            statement.execute("CREATE TABLE IF NOT EXISTS expenses (id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY, label VARCHAR(100) NOT NULL, amount INTEGER NOT NULL CHECK (amount > 0), spent_on DATE NOT NULL)");
        }
    }
    private Expense insert(Connection connection, Expense value) throws SQLException {
        try (PreparedStatement statement = connection.prepareStatement("INSERT INTO expenses(label, amount, spent_on) VALUES (?, ?, ?)", Statement.RETURN_GENERATED_KEYS)) {
            statement.setString(1, value.label()); statement.setInt(2, value.amount());
            statement.setDate(3, Date.valueOf(value.date())); statement.executeUpdate();
            try (var keys = statement.getGeneratedKeys()) {
                if (!keys.next()) throw new SQLException("Insert did not return an id");
                return new Expense(keys.getLong(1), value.label(), value.amount(), value.date());
            }
        }
    }
    public Expense add(Expense value) throws SQLException {
        try (var connection = source.getConnection()) { return insert(connection, value); }
    }
    public void addAll(List<Expense> values) throws SQLException {
        try (var connection = source.getConnection()) {
            connection.setAutoCommit(false);
            try {
                for (Expense value : values) insert(connection, value);
                connection.commit();
            } catch (SQLException | RuntimeException error) {
                try { connection.rollback(); } catch (SQLException rollback) { error.addSuppressed(rollback); }
                throw error;
            }
        }
    }
    public List<Expense> list() throws SQLException {
        var result = new ArrayList<Expense>();
        try (var connection = source.getConnection(); var statement = connection.prepareStatement("SELECT id, label, amount, spent_on FROM expenses ORDER BY id"); var rows = statement.executeQuery()) {
            while (rows.next()) result.add(new Expense(rows.getLong("id"), rows.getString("label"), rows.getInt("amount"), rows.getDate("spent_on").toLocalDate()));
        }
        return List.copyOf(result);
    }
    public List<Expense> findAtLeast(int minimum) throws SQLException {
        var result = new ArrayList<Expense>();
        try (var connection = source.getConnection(); var statement = connection.prepareStatement("SELECT id, label, amount, spent_on FROM expenses WHERE amount >= ? ORDER BY id")) {
            statement.setInt(1, minimum);
            try (var rows = statement.executeQuery()) {
                while (rows.next()) result.add(new Expense(rows.getLong("id"), rows.getString("label"), rows.getInt("amount"), rows.getDate("spent_on").toLocalDate()));
            }
        }
        return List.copyOf(result);
    }
}
```

## Chapter 3: Transactions and connection pools

A transaction groups changes that must succeed or fail together. Disable auto-commit when managing a transaction manually, commit only after all operations succeed, and roll back on failure. In an application, borrow connections from a configured pool and return them promptly.

**Follow the working project:** The rollback test deliberately exceeds the database label limit on the second row. A reopened repository demonstrates persistent storage. Production services should use a configured connection pool, returning borrowed connections promptly.

File in the [reference-project download](/downloads/java-course-labs.zip): `developer-core/src/test/java/in/dailycoder/core/ExpenseApplicationTest.java`. Follow its README to build and run it.

```java
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.io.TempDir;
import org.h2.jdbcx.JdbcDataSource;
import java.nio.file.Path;
import java.time.LocalDate;
import java.time.YearMonth;
import java.util.List;
import static org.junit.jupiter.api.Assertions.*;

class ExpenseApplicationTest {
    @TempDir Path temp;
    private JdbcDataSource dataSource() {
        var source = new JdbcDataSource();
        source.setURL("jdbc:h2:file:" + temp.resolve("expenses")); return source;
    }
    @Test void persistsAcrossRepositoryInstancesAndFiltersMonths() throws Exception {
        var source = dataSource(); var repository = new JdbcExpenses(source);
        repository.add(new Expense(0, "Alice's tea", 1250, LocalDate.of(2026,10,22)));
        repository.add(new Expense(0, "Bus", 300, LocalDate.of(2026,11,1)));
        var reopened = new JdbcExpenses(source);
        assertEquals(2, reopened.list().size());
        assertEquals("Alice's tea", reopened.list().getFirst().label());
        assertEquals(List.of("Alice's tea"), reopened.findAtLeast(1000).stream().map(Expense::label).toList());
        assertEquals(2, reopened.findAtLeast(300).size());
        assertTrue(reopened.findAtLeast(2000).isEmpty());
        var service = new ExpenseService(reopened, (from, to) -> new java.math.BigDecimal("0.5"));
        assertEquals(1250, service.monthlyTotal(YearMonth.of(2026,10)));
        assertEquals(0, service.monthlyTotal(YearMonth.of(2026,9)));
        assertEquals(0, new java.math.BigDecimal("6.25").compareTo(service.convertedMonthlyTotal(YearMonth.of(2026,10), "TEST")));
    }
    @Test void failedBatchRollsBackEarlierRows() throws Exception {
        var repository = new JdbcExpenses(dataSource());
        var date = LocalDate.of(2026,10,22);
        assertThrows(java.sql.SQLException.class, () -> repository.addAll(List.of(new Expense(0,"Valid",100,date), new Expense(0,"x".repeat(101),100,date))));
        assertTrue(repository.list().isEmpty());
    }
    @Test void importsAndExportsEscapedLabelsAndRejectsInvalidInput() throws Exception {
        Path file = temp.resolve("expenses.json");
        ExpenseFiles.write(file, List.of(new Expense(1,"Tea, \"special\"",1250,LocalDate.of(2026,10,22))));
        assertEquals("Tea, \"special\"", ExpenseFiles.read(file).getFirst().label());
        java.nio.file.Files.writeString(file, "[{\"label\":\"Bad\",\"amount\":-1,\"date\":\"2026-10-22\"}]");
        assertThrows(IllegalArgumentException.class, () -> ExpenseFiles.read(file));
    }
    @Test void httpAdapterChecksStatusAndParsesARealLocalResponse() throws Exception {
        var server = com.sun.net.httpserver.HttpServer.create(new java.net.InetSocketAddress("127.0.0.1",0),0);
        server.createContext("/rate", exchange -> {
            byte[] body = "{\"rate\":0.012}".getBytes(java.nio.charset.StandardCharsets.UTF_8);
            exchange.sendResponseHeaders(200,body.length);
            try(var output = exchange.getResponseBody()) { output.write(body); }
        });
        server.createContext("/fail", exchange -> { exchange.sendResponseHeaders(500,-1); exchange.close(); });
        server.createContext("/bad", exchange -> {
            byte[] body = "{\"rate\":-5}".getBytes(); exchange.sendResponseHeaders(200,body.length);
            try(var output = exchange.getResponseBody()) { output.write(body); }
        });
        server.createContext("/invalid-json", exchange -> {
            byte[] body = "not json".getBytes(); exchange.sendResponseHeaders(200,body.length);
            try(var output = exchange.getResponseBody()) { output.write(body); }
        });
        server.createContext("/oversized", exchange -> {
            byte[] body = "x".repeat(65_000).getBytes(); exchange.sendResponseHeaders(200,body.length);
            try(var output = exchange.getResponseBody()) { output.write(body); }
        });
        server.start();
        try {
            String base = "http://127.0.0.1:" + server.getAddress().getPort();
            try(var rates = new HttpExchangeRates(java.net.URI.create(base+"/rate"))) {
                assertEquals(0, new java.math.BigDecimal("0.012").compareTo(rates.rate("INR","USD")));
            }
            for (String route : List.of("/fail", "/bad", "/invalid-json", "/oversized")) {
                try(var rates = new HttpExchangeRates(java.net.URI.create(base+route))) {
                    assertThrows(java.io.IOException.class, () -> rates.rate("INR","USD"));
                }
            }
        } finally { server.stop(0); }
    }
}
```

## Chapter 4: Indexes, constraints, and concurrency

An index trades write cost and storage for faster access patterns. Use uniqueness and foreign-key constraints to protect invariants even when multiple clients write concurrently. Explain plans reveal how a query runs. Application validation alone cannot reliably prevent concurrent duplicate writes.

**Follow the working project:** Inspect EXPLAIN output for the real query and representative data. An index adds storage and write cost. Isolation levels affect what concurrent transactions observe; a preliminary application existence check cannot replace a database uniqueness constraint.

File in the [reference-project download](/downloads/java-course-labs.zip): `backend/src/main/java/in/dailycoder/backend/ExpenseRepository.java`. Follow its README to build and run it.

<details>

```java
package in.dailycoder.backend;

import org.springframework.data.domain.Page;
import org.springframework.data.domain.Pageable;
import org.springframework.data.jpa.repository.JpaRepository;
import org.springframework.data.jpa.repository.Query;
import java.time.LocalDate;
import java.util.Optional;

interface ExpenseRepository extends JpaRepository<ExpenseEntity, Long> {
    Optional<ExpenseEntity> findByIdAndOwner(Long id, String owner);
    Page<ExpenseEntity> findByOwner(String owner, Pageable pageable);
    @Query("select coalesce(sum(e.amount), 0) from ExpenseEntity e where e.owner = :owner and e.spentOn >= :from and e.spentOn < :until")
    long total(String owner, LocalDate from, LocalDate until);
}
```

<details>
<summary>Check your reasoning</summary>
