# Applied Knowledge Check

You've learned how to choose practical JavaScript patterns for object creation, shared services, events, interchangeable behavior, external APIs, wrappers, commands, iteration, dependencies, and composition.

This quiz checks whether you can apply design patterns to realistic JavaScript code and avoid over-engineering.
