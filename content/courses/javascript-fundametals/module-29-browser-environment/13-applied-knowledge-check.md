# Applied Knowledge Check

You've learned how browser JavaScript selects and changes DOM elements, handles events, loads scripts safely, uses browser APIs, works with URLs and storage, and diagnoses common browser-specific bugs.

This quiz checks whether you can choose the right browser API pattern and recognize practical mistakes in DOM, event, storage, script-loading, and security code.

> You need to score **70% or higher** to complete this lesson.
> You can retake the quiz as many times as you like - your best score counts.
