# Applied Knowledge Check

This quiz focuses on the trickier parts of the module: extracting reusable logic, preserving Hook rules, naming custom Hooks, and deciding what API a custom Hook should expose.

Read each question carefully. A useful custom Hook should hide repeated logic without hiding important component behavior.

> You need to score **70% or higher** to complete this lesson and finish the module.
> You can retake the quiz as many times as you like - your best score counts.
